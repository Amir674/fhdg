# Training Planner

**Автор**: Тохчуков Амир

## Описание

Training Planner — это GUI-приложение для планирования и учёта тренировок. 
Позволяет добавлять записи о тренировках, фильтровать их по дате и типу, 
а также сохранять/загружать данные в формате JSON.

## Функциональность

- Добавление тренировок с указанием даты, типа и длительности
- Валидация ввода (формат даты: ГГГГ-ММ-ДД, длительность > 0)
- Просмотр всех тренировок в таблице
- Фильтрация по типу тренировки (частичное совпадение)
- Фильтрация по точной дате
- Удаление выбранных записей
- Автоматическое сохранение в JSON-файл
- Загрузка данных при запуске
